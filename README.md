## 🎯 Meus Projetos

### 🧮 LV MATH - Calculadora
**Descrição**: Uma calculadora em linha de comando desenvolvida em Python puro. Projeto focado em lógica de programação e operações matemáticas básicas.

```bash
python lv_math_calculadora.py
```

**Funcionalidades**:
- ✨ Operações básicas (adição, subtração, multiplicação, divisão)
- ✨ Interface via terminal/console
- ✨ Entrada do usuário simples e intuitiva
- ✨ Tratamento de erros básico

**Como Usar**:
1. Execute o arquivo Python
2. Insira os números e a operação desejada
3. Veja o resultado instantaneamente

---

### 🖥️ LV MATH VERSÃO DIGITAL
**Descrição**: Uma versão aprimorada do LV MATH com interface gráfica. Este projeto demonstra como levar a mesma lógica de calculadora para uma interface visual amigável e moderna.

```bash
python lv_math_digital.py
```

**Funcionalidades**:
- ✨ Interface gráfica intuitiva
- ✨ Botões para cada operação
- ✨ Display de resultado em tempo real
- ✨ Design limpo e fácil de usar
- ✨ Mesmas operações matemáticas da versão console

**Como Usar**:
1. Execute o arquivo Python
2. Uma janela com a calculadora aparecerá
3. Clique nos botões para realizar operações
4. Veja os resultados no display

## 🚀 Como Usar

### Pré-requisitos
- **Python 3.6+** instalado em sua máquina
- Terminal/Prompt de Comando

### Passo a Passo

1. **Clone o repositório**:
```bash
git clone https://github.com/lohangomes786-oss/projetos-python.git
cd projetos-python
```

2. **Para executar a Calculadora (versão console)**:

3. **Para executar a Calculadora (versão digital com interface gráfica)**:
